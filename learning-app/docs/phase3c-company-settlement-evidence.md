The operator-only `POST /api/admin/payments/company-settlement/record-live` route requires a same-origin Learning Admin session and `PAYMENTS_LIVE_COMPANY_SETTLEMENT_RECORDING_ENABLED=true`. That flag defaults to false. Input is only `{ "purchaseId": 123, "settlementId": "456" }`; the transaction identity and amount come from the immutable sale, not the request. The server re-fetches the complete matching settlement and transaction from Paystack with the configured Live key before calling the recorder. A missing Live configuration, incomplete provider pagination, mismatch, missing migration, or disabled flag fails closed.
